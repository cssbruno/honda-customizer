# Honda Civic OEM implementation evidence

Honda Customizer remains a separate FYT-only app; see [the app README](../../../README.md). Honda controls are also available inside Cabin.

This source distribution includes the implementation, derived setting metadata, research reports and verification artifacts. Original proprietary firmware binaries, decompiled vendor classes and raw resource dumps are not included. Source references in the research reports identify the locally inspected firmware evidence; absolute local paths are provenance references, not build dependencies. The app builds from its bundled source and assets.
